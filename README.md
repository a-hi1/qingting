# 轻听 QINGTING · 产品介绍页

一个虚构的音乐播放器的产品落地页。单文件 HTML，零依赖，零构建。

> 本页为前端设计与交互演示，产品、品牌与数据均为虚构。

---

## 品牌

- **名称**：轻听 / QINGTING
- **标识**：一片飘落的叶 + 三柱声波 —— 叶是「轻」，声波是「听」
- **字标**：中文用宋体，拉丁用等宽字母拉开字距
- **主色**：樱粉 #ff7eb3 → 紫 #a98bff

---

## 内容结构

| 区块 | 内容 |
|---|---|
| **导航** | 悬浮胶囊导航，滚动时高亮当前区块、加投影；移动端折叠 |
| **首屏** | 主标题 + 手机样机 + 三张漂浮信息卡 + 竖排装饰字 |
| **跑马灯** | 无限横向滚动带，悬停暂停 |
| **产品特性** | 三张卡片，鼠标移入有跟随光标的光晕 |
| **现场体验** | 可操作的播放器：标签切换、点歌词跳转、拖音量、换主题色 |
| **组件手册** | 按钮 / 开关 / 分段控件 / 进度环 / 头像组 / 气泡提示 / 滑块 |
| **一些数字** | 滚动进入时数字滚动 |
| **收尾** | 大圆角 CTA 面板 + 页脚 |

---

## 交互清单

- 悬浮导航随滚动变实、自动高亮当前区块
- 全站滚动出现动画（IntersectionObserver）
- **播放器**：播放/暂停、点歌词跳转、点进度条跳转、音量滑块实时填充
- **主题色切换**：四个圆点切换主色，全站 CSS 变量联动（按钮、开关、高亮歌词、进度环一起变色）
- 标签页切换（歌词 / 歌单）
- 开关、分段控件、气泡提示、数字滚动
- 樱花飘落（Canvas，22 片，各自速度与摆幅）
- **手机样机曲目轮播**：点下一首 / 上一首 / 点封面 / 左右滑动，封面渐变、太阳位置、歌名、时长、进度、"接下来"队列一起切换，带滑入淡出过渡
- 响应式：960px / 640px 两档断点

---

## 技术说明

- **纯手写**，没有用任何 UI 组件库、没有构建工具、没有外部字体与图片
- 图标与标识全部为内联 SVG，含 favicon（data URI，零请求）
- 配色、圆角、阴影统一由 CSS 变量控制
- 动效以 CSS transition / keyframes 为主，只有樱花、歌词滚动和数字滚动用 JS
- 单文件，`index.html` 直接双击即可运行
